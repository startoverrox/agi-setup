# 템플릿 — `Me/Understanding.md`

> 매 세션 시작에 읽고, 매번 갱신하는 파일. 이 시스템의 핵심 자산.

---

```
# 내가 이해한 당신

> **읽는 법**
> - **사실** — 당신이 직접 말한 것. 확신도 표기 없음.
> - **해석** — 내가 추론한 것. `⚠️ 확신도: 높음/중간/낮음` 표기.
> - **당신이 확인한 해석은 확신도 표기를 지워주세요.** 표기가 남아 있으면 미검증이라는 뜻입니다.
> - 틀린 줄에는 `← 틀림: (이유)`를 달아주세요.
>
> 최종 갱신: YYYY-MM-DD HH:MM

---

## <이해 제목>
- **사실**
  - <!-- 사용자가 직접 말한 것. 가능하면 원문에 가깝게. 언제 말했는지 (YYYY-MM-DD) -->
- **해석** — <!-- 한 줄 요약 --> — ⚠️ 확신도: 높음/중간/낮음
  <!-- 해석 상세. 무엇을 근거로 그렇게 봤는지 포함. -->

## <이해 제목>
...
```

---

## 확신도 기준

| 확신도   | 언제                                                     |
| -------- | -------------------------------------------------------- |
| **높음** | 사용자가 직접 말한 것에서 한 단계만 추론. 반대 증거 없음 |
| **중간** | 여러 관찰을 묶어 추론. 다르게 해석할 여지 있음           |
| **낮음** | 관찰 1~2건에서 추론. 틀릴 가능성이 꽤 있음               |

**확신도는 올라가기만 하지 않는다.** 반대 증거를 보면 내린다.

**사실과 해석을 섞지 않는다.**
"바쁘다고 했다"는 사실. "시간 압박을 받고 있다"는 해석.

## 갱신 기준

- 새로 안 것 추가
- 틀린 것 수정 (이유는 남기지 않는다)
- 사용자가 확신도 표기를 지운 줄은 "검증됨"이다. 다시 표기를 붙이지 않는다
- `← 틀림:` 이 달린 줄은 다음 갱신에서 **최우선으로** 처리한다
