# AGI

사용자처럼 생각하되 사용자보다 빠른 에이전트.

에이전트는 `AGENTS.md`를 읽고 일하고, 일한 결과를 아래 폴더에 남긴다.

---

## 5분 안에 시작하기

**1. `Me/About Me/`를 채운다.** 13개 파일이 있고 대부분 비어 있다.
전부 채울 필요 없다. **지금 대화에 영향을 줄 것부터** 채운다.

| 먼저 채우면 좋은 것 | 왜                                                                    |
| :------------------ | :-------------------------------------------------------------------- |
| `전문 스킬.md`      | 설명을 어디서부터 시작할지가 정해진다. 아는 것을 다시 설명하지 않는다 |
| `우선순위.md`       | 선택지를 낼 때 무엇을 추천할지가 갈린다                               |
| `하기싫은 것.md`    | 시키지 않아도 알아서 피한다                                           |
| `사용 가능한 툴.md` | 없는 도구를 전제한 제안을 안 하게 된다                                |

형식은 없다. 문장이 안 돼도 된다. 빈 파일은 에이전트가 건너뛴다.

**2. 인터뷰에 응한다.** 에이전트가 알아야 할 게 있으면 `Me/Interview.md`에 질문을 남긴다.
틈날 때 `**A**` 뒤에 답을 쓰면 된다. 한 번에 다 답할 필요 없다.
답한 질문은 `Me/Understanding.md`로 정리되고 인터뷰에서는 사라진다.

**3. 생각나는 건 `Me/Braindump.md`에 던져둔다.** 정리는 에이전트가 한다.

## 사용자가 해야 하는 일 — 딱 세 가지

**1. `Me/Understanding.md`를 가끔 읽고 고친다.**
`⚠️ 확신도:` 가 붙은 줄은 에이전트의 추측이다.
맞으면 그 표기를 **지운다** — 표기가 없는 줄이 검증된 줄이다.
틀리면 그 줄에 `← 틀림: (이유)`를 단다. 다음 갱신에서 최우선으로 고쳐진다.

**2. 개념 설명을 들었으면 이해했는지 말해준다.**
`Glossary/_INDEX.md`의 "이해 완료"에 올라간 개념만 설명 없이 쓰인다.
"아 네"는 확인이 아니다. "알겠다"거나 자기 말로 다시 설명하면 확인이다.

**3. 선택지가 나오면 고른다.**
에이전트는 되돌리기 어렵거나 취향이 걸린 지점에서 선택지를 만들고 멈춘다.
고르기 전까지 결론을 쓰지 않는다.

---

## 에이전트에게 기대하면 안 되는 것

- **`AGENTS.md`와 `Template/`를 스스로 고치는 것.** 잠겨 있다.
- **`Me/About Me/`와 `Me/Braindump.md`를 고치는 것.** 사용자의 말이라 건드리지 않는다.
- **파일을 지우는 것.** 지우지 않는다. 내용 편집만 한다.
- **확신 없이 확신하는 것.** 추측에는 `⚠️ 추측:` 이 붙는다. 맞으면 그 표기를 사용자가 지운다.
